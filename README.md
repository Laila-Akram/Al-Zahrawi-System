# AL-ZAHRAWI

**Inspired by history, built for modern dentistry.**

AL-ZAHRAWI is a full-stack web application that connects dental clinics and doctors with dental suppliers. It simplifies the process of requesting dental products, receiving supplier offers, and choosing the most suitable offer.

## Features

### Doctor
- Register and log in.
- Create and manage product requests.
- View and compare supplier offers.
- Accept an offer.
- Rate suppliers.

### Supplier
- Register and log in.
- Browse doctors' product requests.
- Submit offers.
- Manage submitted offers.
- Update profile information.

### Admin
- Manage users and account approvals.
- Manage products and categories.
- View and manage supplier ratings.

## Technologies Used

**Frontend**
- React
- Vite
- Bootstrap

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Tokens (JWT)
- Google Authentication

## Project Structure

- `frontend/` — React application.
- `backend/` — Express API and database models.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Laila-Akram/Al-Zahrawi-System.git
cd Al-Zahrawi-System
```

### 2. Install backend dependencies

```bash
cd backend
npm install
```

Configure your backend environment variables in a `.env` file.

### 3. Run the backend

```bash
npm run dev
```

### 4. Install frontend dependencies

Open another terminal:

```bash
cd frontend
npm install
```

### 5. Run the frontend

```bash
npm run dev
```

## Project Goal

The goal of AL-ZAHRAWI is to make dental supply purchasing easier by providing a digital platform for communication between dental professionals and suppliers.
